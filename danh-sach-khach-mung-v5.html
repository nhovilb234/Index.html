📱 Cách chia sẻ qua Zalo / Messenger / Gmail
1
Nhấn một trong các nút xuất PDF bên trên → file PDF tự tải về điện thoại
2
Mở Zalo / Messenger / Gmail → chọn người nhận
3
Nhấn biểu tượng 📎 đính kèm file → chọn file PDF vừa tải (thường ở thư mục Download)
4
Gửi đi! Người nhận có thể mở xem ngay trên điện thoại
